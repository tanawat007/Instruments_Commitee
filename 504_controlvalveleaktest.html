เกณฑ์มาตรฐานสากล

  • Class II, III, IV: 0.5%, 0.1%, และ 0.01% ของ Rated Capacity (Cv) ตามลำดับ มักใช้กับ Metal-to-Metal Seat
  • Class V: ทดสอบด้วยน้ำ (Water Test) คำนวณจาก Size และ ความดัน ΔP (เหมาะสำหรับ High Temp / Critical Service)
  • Class VI: ทดสอบด้วยอากาศ/ก๊าซ (Bubble Test) ใช้กับ Soft Seat (Teflon/Elastomer) ปิดสนิทที่สุด

คำแนะนำหน้างาน (Field Instruction)

การทดสอบควรทำที่ความดันใช้งานจริง (Service ΔP) หรือ 50 psi สำหรับ Class VI

หากใช้ของเหลวทดสอบ (Water Test) ต้องไล่อากาศ (Venting) ออกจากระบบให้หมดก่อน เพื่อป้องกัน Error จาก Air pocket ที่บีบอัดตัวได้
